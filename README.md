# DEADBLOCK: Аванпост

Публичный репозиторий разрабатываемой Roblox-игры: зомби-тайкун с обороной турелями.

Ты командир аванпоста посреди заражённой земли. Завод кормит оборону, оборона защищает завод. Каждая волна проверяет решения: какие турели, где, что улучшить. Захватив мир, открываешь портал дальше.

Это рабочая версия в разработке. Игра ещё не опубликована на Roblox.

## Что уже есть

- **Завод и экономика.** Шесть дропперов на общем конвейере, уровни дропперов с потолком по миру, цехи открываются у своих ворот.
- **База-аванпост.** Одна стена-периметр, которая растёт с уровнем базы (4 уровня). Внутри завод, реактор-ядро, командный пункт, мастерская, портал.
- **Пять турелей с ролями** на строительных площадках: пулемёт, огнемёт, снайпер, тесла, миномёт. Панель площадки: построить, улучшить, продать, модули за ядра (урон, скорострельность, дальность).
- **Зомби с разными ролями:** ходячий, бегун, громила в броне, взрыватель, плевун, лекарь, щитоносец, летун и Колосс — босс каждой 10-й волны. Волны бесконечные, идут с 1–4 сторон, состав виден заранее.
- **Ядро — последний рубеж** со своей пушкой. При поражении волна начинается заново, игра объясняет, кто прорвал оборону.
- **Инженеры** чинят стены во время боя, ремонт и укрепление стен — у командного пункта.
- **Миры и сложность.** Три мира (Лес, Пустошь, Город) с ростом силы зомби, дохода и потолка уровней. Портал открывается после победы над первым Колоссом. В каждом мире три сложности: Обычная, Тяжёлая, Кошмар.
- **Первые минуты.** Цепочка из 10 заданий с золотой стрелкой-подсказкой, бесплатная первая турель, ближние первые волны, автостарт волн, звуки.
- **Возврат в игру.** Ядра как вторая валюта, перегрев завода, офлайн-доход завода, задания дня и серия входов.
- **Общий онлайн.** Площадь в центре с телепортами и табло, бластер у каждого игрока, помощь соседу во время волны (без PvP), общий босс Титан на площади, бонус за друга на сервере, табло рекордов.
- **Сохранения** через DataStore с блокировкой сессии и защитой от перезаписи. В Studio выключены, пока в `ServerStorage` не задан атрибут `DeadblockStudioSaves = true` (используйте отдельную тестовую игру).

Вся логика серверная: клиент отправляет только намерения, цены и урон считает сервер.

## Устройство

| Папка | Содержимое |
|---|---|
| `src/shared` | `Config` (весь баланс), `TurretMath` (формулы для сервера и интерфейса) |
| `src/server` | Чистые модели (`TycoonModel`, `SiegeModel`, `WaveGenerator`, `CompoundLayout`, `DailyModel`, `QuestRules`) и сервисы, которые связывают их с миром и клиентами |
| `src/client` | HUD, панель площадки, рендер зомби и эффектов, стрелка-подсказка, бластер |
| `tests` | 91 проверка чистой логики (экономика, осада, сохранения, задания, сложность) |
| `tools` | Сборка мира (`BuildOutpost.luau`), список файлов для Studio (`manifest.json`), инструмент деплоя и тестов (`DevTool.luau`) |

Зомби на сервере — только данные. Клиент получает сжатые снимки и пакеты эффектов и рисует всё сам.

## Как собрать в Roblox Studio

1. Откройте отдельную тестовую сцену (Baseplate).
2. Разложите файлы по путям из `tools/manifest.json`: модули — ModuleScript, `Main` — Script, клиентские файлы — LocalScript в `StarterPlayer/StarterPlayerScripts`, тесты — в `ServerStorage/DeadblockTests`.
3. Либо запустите в корне репозитория `python -m http.server 8765`, разово включите **Allow HTTP Requests** и выполните `tools/DevTool.luau` в Edit-режиме: он сам разложит скрипты, создаст RemoteEvent, прогонит тесты и соберёт мир (`{deploy=true,test=true,build=true}`). Если в сцене уже есть `DeadblockWorld`, сборка потребует резервную копию в `ServerStorage` и не заменит неизвестный мир.
4. Запустите Play.
